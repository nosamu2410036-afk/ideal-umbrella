# 養豚場 日報 自動化ツール

「1日1シート」で記録する養豚場の日報 Excel を自動化します。
中豚舎1〜8・肉豚舎1〜8・9豚舎の在庫／死亡／出荷／移動と、本日・週・月の累計、
事故率を扱います。

2通りの形式を用意しています。用途に合わせて選べます。

- **VBA版（`vba/NippoAuto.bas`）** … Excel内のボタンで操作。Python不要。`.xlsm`保存が必要。
  → [VBA版の使い方](#vba版excel内ボタン) へ。
- **Python版（`nippo.py`）** … コマンドで実行。`.xlsx`のまま使え、この環境で実機検証済み。

> 結合セルが多いブックでも問題ありません。書き込む値はすべて結合範囲の「左上セル」に
> 入るため、VBA・Pythonどちらでも正しく動作します（実ファイルで確認済み）。

---

## VBA版（Excel内ボタン）

### 導入手順

1. Excelで日報ブックを開く
2. `Alt`+`F11` でVBエディタを開く
3. メニュー **[挿入]→[標準モジュール]**
4. `vba/NippoAuto.bas` の中身を**すべてコピーして貼り付け**
   （日本語が文字化けする場合は、ファイルを開いてコピー＆貼り付けしてください）
5. 日報のシート上で `日報_ボタン設置` を一度実行（`Alt`+`F8` → 選択 → 実行）
6. **[ファイル]→[名前を付けて保存]** で、ファイルの種類を
   **「Excel マクロ有効ブック (*.xlsm)」** にして保存

ボタンを設置したシートを「翌日シート作成」で複製すると、ボタンも自動で引き継がれます。

### 操作（ボタン または `Alt`+`F8`）

| マクロ名 | 内容 |
|---|---|
| `日報_翌日シート作成` | 最新シートを複製して翌日シートを作成（日付更新・本日欄リセット・週/月累計の自動リセット） |
| `日報_本日入力` | 死亡/出荷/移動をダイアログで入力（例 `中1=2,肉4=3`）し、本日・週・月の累計を更新 |
| `日報_月次集計` | 「月次集計」シートに**号別（中豚舎1〜8号・肉豚舎1〜8号）＋9号残豚＋累計**の導入・死亡・出荷・事故率を出力 |
| `日報_チェック` | 在庫マイナス・事故率異常・日付抜けを「チェック結果」シートに出力 |

> VBA版の利点：シート複製にExcel標準機能を使うため、**結合セル・コメント・印刷設定・
> 書式が完全に保持**されます。
>
> ⚠ 注意：このコードは作成環境にExcelが無いため**実行検証はできていません**
> （ロジックは実機検証済みのPython版と同一です）。初回は動作をご確認ください。

## Python版（コマンドライン）

### できること

| サブコマンド | 内容 |
|---|---|
| `next-day` | 最新シートを複製して**翌日シート**を作成（日付更新・本日欄リセット・週/月累計の自動リセット） |
| `record`   | **本日の死亡・出荷・移動**を各房に追記し、本日／週／月の累計を更新 |
| `report`   | 全シート横断の**月次集計**（号別＋9号残豚＋累計の導入・死亡・出荷・事故率）を表示／CSV出力 |
| `check`    | **入力チェック**（在庫マイナス・事故率異常・日付抜け・本日死亡の整合）|

## 設計上の安全性

- Excel が付けている**セルのコメント枠・印刷設定・書式・結合セル**を壊さないよう、
  ファイル全体を再保存せず ZIP/XML を**必要な箇所だけ**書き換えます。
- 書き換えたセルは Excel で開いた時に**自動再計算**されます（`fullCalcOnLoad`）。
- 集計・チェック（`report`/`check`）は数式を自前で評価するため、Excel で開き直す前でも
  正しい値で判定します。

> ⚠ 上書き保存します。`--out` で別ファイルに出力できます。心配な場合は元ファイルの
> バックアップを取るか `--out` を使ってください。

## 必要なもの

- Python 3.8 以上（標準ライブラリのみ。`report`/`check`/`next-day`/`record` に追加依存なし）

## 使い方

ファイル名はご自身の日報ファイルに置き換えてください（以下 `日報.xlsx`）。

### 1. 翌日シートを作る

```bash
# 最新シートの翌日を自動作成（例: R8.6.13 → R8.6.14）
python3 nippo.py -f 日報.xlsx next-day

# 日付や複製元を明示することも可能
python3 nippo.py -f 日報.xlsx next-day --date 2026-07-01
python3 nippo.py -f 日報.xlsx next-day --from-sheet R8.6.13
```

- **月曜**に作成すると週累計（E列）を、**1日**に作成すると月累計（G列）を自動で `0` に
  戻します。戻したくない場合は `--no-week-reset` / `--no-month-reset` を付けます。

### 2. 本日の死亡・出荷・移動を記録

房は `中1`〜`中8` / `肉1`〜`肉8` で指定します。

```bash
# 最新シートに記録（死亡：中1が2頭・肉4が3頭、出荷：肉6が40頭・肉7が22頭）
python3 nippo.py -f 日報.xlsx record --death "中1=2,肉4=3" --ship "肉6=40,肉7=22"

# シートと移動・導入も指定する例
python3 nippo.py -f 日報.xlsx record --sheet R8.6.14 \
    --death "中1=1" --move "肉6=99" --intro 415
```

- 本日合計（C23 死亡 / C20 出荷 / C27 導入）と、週・月の累計に自動で反映します。
- 9豚舎の死亡や新群導入（バッチ入替）は対象外です（別途手入力してください）。

### 3. 月次集計

```bash
python3 nippo.py -f 日報.xlsx report
python3 nippo.py -f 日報.xlsx report --csv 月次集計.csv
```

各月末（棚卸でない最終日）シートを基準に、**号別（中豚舎1〜8号・肉豚舎1〜8号）＋9号肉豚舎残豚＋累計**
の **導入・死亡・出荷・事故率** を縦持ちの一覧（月・区分・導入・死亡・出荷・事故率）で表示します。
- 各房の値は「導入からの累計」（導入頭数＝頭数式の先頭定数、死亡・出荷＝各房の累計）。
- 9号残豚は 導入＝受入(J124)／死亡＝今月死亡(N124)／出荷＝L124。
- 累計は 導入＝中+肉（9号は二重計上回避）、死亡・出荷＝中+肉+9号。
- 中豚舎の出荷は通常0です（中豚は肉豚舎へ「移動」してから出荷されるため）。

### 4. 入力チェック

```bash
python3 nippo.py -f 日報.xlsx check
python3 nippo.py -f 日報.xlsx check --rate-threshold 10
```

- 在庫がマイナスになった房（出荷・死亡の入れすぎなど）
- 月事故率が閾値（既定 8%）を超えた月
- シートの日付抜け
- 本日死亡（C23）と各房＋9豚舎の死亡増分の不一致

を警告します。問題があれば終了コード 1 を返します。

## 典型的な1日の流れ

```bash
python3 nippo.py -f 日報.xlsx next-day                          # 朝：翌日シート作成
python3 nippo.py -f 日報.xlsx record --death "中3=1,肉2=2" \    # 当日：実績入力
                                     --ship "肉6=40"
python3 nippo.py -f 日報.xlsx check                             # 確認
```

## 房とセルの対応（参考）

- 中豚舎 1〜8 … 行 105,107,…,119 / 頭数=C 死亡=E 移動=G 出荷=I
- 肉豚舎 1〜8 … 行 105,107,…,119 / 頭数=N 死亡=P 移動=R 出荷=T
- 本日 C20(出荷)/C23(死亡)/C27(導入)、週 E20/E23/E27、月 G20/G23/G27
- 日付 A1、9豚舎死亡 N124
